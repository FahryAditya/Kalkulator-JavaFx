# Kalkulator JavaFX

Sebuah aplikasi **kalkulator sederhana** yang dibuat menggunakan **JavaFX**. Aplikasi ini mendukung operasi matematika dasar seperti penjumlahan, pengurangan, perkalian, dan pembagian.

## Fitur

- Penjumlahan (`+`)
- Pengurangan (`-`)
- Perkalian (`*`)
- Pembagian (`/`)
- Clear (`C`) untuk menghapus input
- Tampilan GUI sederhana dan responsif menggunakan JavaFX
